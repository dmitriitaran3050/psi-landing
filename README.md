# Мини-лендинг выбора мессенджера

Статичный лендинг для записи на психологическую игру про денежный запрос через Max, Telegram или VK.

## Файлы

- `index.html` — разметка первого экрана, кнопки регистрации и Яндекс.Метрика.
- `styles.css` — mobile-first стили без сборщика.
- `script.js` — цели Яндекс.Метрики для кликов по мессенджерам.
- `assets/` — SVG-иконки Max, Telegram и VK.
